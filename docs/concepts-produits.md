# Concepts Produits Évalués

## Concept 1 : 🏆 CHARTAPI — Le Twilio de la Music Data

### Positionnement
API REST temps réel pour données de charts musicaux. Le "Twilio" de la musique — simple, abordable, developer-first.

### Données Disponibles
- Charts iTunes (100+ pays)
- Charts Spotify (50+ pays)
- Charts YouTube Music
- Charts Shazam
- Données historiques archivées

### Pricing
| Plan | Requêtes/mois | Prix | Features |
|---|---|---|---|
| Free | 10,000 | \$0 | Accès basique, 1 endpoint |
| Starter | 100,000 | \$9.99 | Tous endpoints, historique 30j |
| Pro | 1,000,000 | \$29 | Historique complet, alertes, webhooks |
| Enterprise | Custom | Sur devis | SLA, support prioritaire, cluster dédié |

### Métriques Clés
- **MVP :** 10 jours solo maker
- **Coût infra :** \$5.83/mois (MVP)
- **Stack :** Cloudflare Workers + D1 + KV + R2 + Supabase + n8n + Next.js
- **Seuil de rentabilité :** Mois 2
